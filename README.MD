# 🔐 Password Generator

A simple and secure desktop Password Generator built using Python and Tkinter.

## 📌 Project Description

Password Generator is a Python-based desktop application that generates random and strong passwords according to the length specified by the user.

The generated password contains a combination of:

- Lowercase letters (a-z)
- Uppercase letters (A-Z)
- Numbers (0-9)
- Special characters

This project demonstrates the use of Python functions, randomization, string handling, exception handling, and GUI development using Tkinter.

## ✨ Features

- Generate random passwords
- Choose custom password length
- Includes uppercase and lowercase letters
- Includes numbers
- Includes special characters
- Copy generated password to clipboard
- Clear input and generated password
- Simple and user-friendly GUI
- Input validation and error handling

## 🛠️ Technologies Used

- Python 3
- Tkinter
- Random Module
- String Module
